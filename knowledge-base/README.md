# Knowledge Base

**Open this folder as an Obsidian vault.** In Obsidian: *Open folder as vault* → select this `knowledge-base/` directory.

Write your notes here. Claude reads these files as context.

---

## Two-Layer System

| Layer | Directories | Who writes | Purpose |
|-------|------------|------------|---------|
| Human layer | `domains/`, `research/`, `meta/` | You, in Obsidian | Informal notes, theses, watchlists |
| Machine layer | `context/` | Claude | Synthesised summaries optimised for AI consumption |

Write freely in Obsidian. Claude reads your notes and maintains the `context/` layer.

## Structure

```
knowledge-base/
├── research/
│   ├── journal/        — timestamped research entries (YYYY-MM-DD-topic.md)
│   ├── theses/         — one file per investment thesis
│   └── watchlists/     — equities.md, crypto.md
├── domains/
│   ├── equities/       — equity research notes
│   ├── crypto/         — crypto research notes
│   ├── macro/          — macro notes
│   └── commodities/    — commodities notes
├── context/            — AUTO-GENERATED by Claude, do not edit manually
│   ├── domain-summaries/
│   └── active-context.md
├── meta/
│   ├── preferences.md
│   ├── glossary.md
│   └── lessons-learned.md
└── templates/          — use these when creating new entries
```

## Slash Commands (in Claude Code)

| Command | What it does |
|---------|-------------|
| `/research <topic>` | Structured research session with journal entry output |
| `/thesis <asset> <direction> <conviction>` | Create a new investment thesis |
| `/learn` | Extract session insights and update context layer |
| `/context-update [domain]` | Re-synthesise context from latest notes |
| `/status` | Overview of knowledge base state and staleness |
