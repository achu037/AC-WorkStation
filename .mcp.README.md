# MCP Server Configuration

This workspace uses [Model Context Protocol (MCP)](https://modelcontextprotocol.io) servers to extend Claude Code with additional capabilities.

## Active Servers

| Server | Purpose | Requires |
|--------|---------|---------|
| `filesystem` | Extended file read/write scoped to repo root | Nothing (auto-installs via npx) |
| `github` | PRs, issues, code review, repo management | `GITHUB_TOKEN` in `.env` |
| `fetch` | Fetch web content, articles, financial reports | Nothing |

## Setup

1. Copy `.env.example` to `.env` and fill in tokens:
   ```bash
   cp .env.example .env
   ```
2. Restart Claude Code: `exit` then `claude`
3. Verify servers are running: type `/mcp` inside Claude Code

## Adding a New Server

Add an entry to `.mcp.json` under `mcpServers`:

```json
"my-server": {
  "command": "npx",
  "args": ["-y", "@scope/mcp-server-name"],
  "env": {
    "API_KEY": "${MY_API_KEY}"
  }
}
```

Then restart Claude Code and run `/mcp` to confirm it appears.

## Troubleshooting

- **Server not appearing in `/mcp`:** Check that the token is set in `.env` and restart Claude Code.
- **npx install fails:** Run `npx -y @anthropic/mcp-server-<name>` manually to check for errors.
- **Permission errors:** Ensure the filesystem path in `.mcp.json` matches your actual repo path.
